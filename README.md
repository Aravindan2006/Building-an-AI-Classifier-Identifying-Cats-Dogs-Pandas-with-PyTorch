# Building-an-AI-Classifier-Identifying-Cats-Dogs-Pandas-with-PyTorch
## 📌 Overview
A Deep Learning project that classifies images as **Cat** or **Dog** using a Convolutional Neural Network (CNN) built with PyTorch.

## 🛠️ Technologies
- Python
- PyTorch
- Pandas
- NumPy
- Matplotlib
- Torchvision

## 📂 Dataset
- Cats Images
- Dogs Images

## 🚀 Features
- Image preprocessing
- CNN model training
- Model evaluation
- Cat/Dog prediction

## ▶️ Usage

```bash
pip install -r requirements.txt
python train.py
```

## 📊 Result
Achieved high accuracy in classifying cat and dog images.
